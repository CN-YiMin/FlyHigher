# Local compile-only dependencies

These jars are supplied by the pack at runtime and are intentionally not
committed to the repository.

Place these files here before running Gradle:

- `sable-neoforge-1.21.1-2.0.6.jar`
- `cloth-config-15.0.140-neoforge.jar`

They are on the compile classpath only; the built jar does not bundle them.
